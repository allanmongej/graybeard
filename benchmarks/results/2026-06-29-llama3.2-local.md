# Graybeard Local Benchmark - llama3.2

Date: 2026-06-29

## Setup

- Harness: `python3 benchmarks/benchmark-local.py --model llama3.2 --repeat 3`
- Provider: local Ollama
- Model: `llama3.2:latest`
- Arms: `baseline`, `caveman`, `graybeard`
- Tasks: `email`, `debounce`, `csv-sum`, `countdown`, `rate-limit`
- Statistic: median of 3 runs per arm/task
- Raw responses: `benchmarks/results/2026-06-29-llama3.2-local.json`

## Median Code LOC

| arm | email | debounce | csv-sum | countdown | rate-limit | total |
|---|---:|---:|---:|---:|---:|---:|
| baseline | 13 | 14 | 26 | 41 | 27 | 121 |
| caveman | 18 | 16 | 28 | 48 | 28 | 138 |
| graybeard | 19 | 18 | 26 | 45 | 34 | 142 |

## Median Latency

| arm | email | debounce | csv-sum | countdown | rate-limit | total |
|---|---:|---:|---:|---:|---:|---:|
| baseline | 2.8s | 5.6s | 4.9s | 5.7s | 6.3s | 25.3s |
| caveman | 7.4s | 6.1s | 6.1s | 6.5s | 10.0s | 36.1s |
| graybeard | 7.2s | 4.8s | 5.6s | 7.5s | 8.2s | 33.3s |

## Result

On this small local model and task set, Graybeard did not reduce generated code
size. It produced 142 median LOC, which is 17% more than the 121 LOC baseline.
It was also slower than baseline, with 33.3s aggregate median latency versus
25.3s.

This is still useful signal: Graybeard's senior-dev guidance should not claim a
LOC reduction until the broader correctness and agentic harnesses prove that
the extra output buys better repo-fit, test discipline, safety, or correctness.

## Limitations

- This local harness measures generated code LOC and wall-clock latency only.
- It does not execute the generated code or score semantic correctness.
- It does not measure cost because Ollama does not expose provider billing.
- The prompts are small single-shot tasks, not full repository edits.
- Anthropic Haiku was attempted on 2026-06-29 but could not run because the
  configured account had insufficient API credits.
- OpenCode exposes `opencode-go/deepseek-v4-flash` with `--variant max`, but a
  noninteractive smoke run produced no output before a 45-second timeout. No
  DeepSeek result is published from that attempt.
